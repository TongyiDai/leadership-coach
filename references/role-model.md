# 情境范本 · 学"这种情况怎么处理"（阶段 3.5，可选）

这个 skill 不止照出你的问题，还能帮你看到：在**同类情境**下，更好的处理方式长什么样。做法来自你**一起开过的会**里真实发生过的正向片段——但**一律脱敏、不点名**。你需要的是"这种场合该怎么接、怎么问、怎么推"的**体感**，而不是"谁这么做的"。去掉姓名，既避免同事间攀比，也让注意力回到行为本身。

## 为什么强制匿名

- **价值在情境处理，不在人**：用户要学的是"跨部门有分歧时，怎么先接住对方顾虑再推进"，这个做法谁演示的不重要。
- **防攀比、防画像**：点名会把"行为"变成"对某人的评价与比较"，既伤关系，也越过"不评判他人"的边界。
- **更聚焦**：匿名后，用户不会纠结"他行我不行"，而是直接代入"下次我可以这么接"。

## 与"不评判他人"边界自洽

- ✅ **做**：以本人学习为唯一目的，呈现**匿名的、正向的、可模仿的行为片段**（"这种情况这样处理更好"）。
- ❌ **不做**：点名、给同事打分/排名、评判谁强谁弱、生成"同事画像"、推测动机、任何负面评价或比较。

焦点始终是"我怎么处理这类情境"，他人只是**匿名的行为范本**。

## 触发

阶段 3 诊断出用户某方向薄弱后，主动问一句（不要默认执行）：

> "要不要我从你们一起开过的会里，找找**这类情况更好的处理方式**？我会脱敏，只讲做法、不点名。"

用户要，才进入。

## 取证

- **只用共同会议**：复用阶段 2 已取的、用户**本人也参与**的会议逐字稿。不为找范本额外翻用户没参加的会、不去搜特定某人的所有发言（那是画像）。
- **锚定薄弱方向**：只在用户诊断出的薄弱方向上找正向片段。例如用户"只给结论不提问"，就找会上**有人用开放式问题带动讨论**的片段。
- **抓情境，不抓人**：提取的是"这个情境 + 这个做法"，不是"谁是好领导"。

## 产出结构（每条情境范本）

```
【情境】<什么场合、遇到什么>（如：跨部门会上对方对方案有抵触）
【更好的处理】<一句话：一个具体、可复制的做法>
【真实片段（脱敏）】<那次会上的原话/做法，说话人一律用"有人 / 一位与会者"，去掉姓名和与学习无关的敏感信息>
【为什么有效】<挂框架：如"GROW 的 Options——先问'你会怎么做'，把方案权交回对方">
【对照你的差距】<你在同类场景通常怎么做，差在哪>
【下次可以怎么试】<你下一场会能直接照搬的动作/话术>
```

一次最多给 2–3 条，选最对口的。可把其中一条设为阶段 4 陪练的演练目标。

## 脱敏规则（强制，不可协商）

- **一律不点名**：说话人统一用"有人 / 一位与会者 / 会上另一方"指代，绝不出现真实姓名、花名、职位头衔、能反推身份的独特线索。
- **对话里也不点名**：不只是落盘匿名——即使在对话中，也不说"是 XX 做的"。用户主动追问"是谁"时，说明本 skill 只学做法、不点名，把话题拉回"这个做法你怎么用上"。
- **不写入任何持久层**：`outputs/` 报告、`state.json`、记忆锚点里都只有脱敏后的情境范本，无姓名。
- **只正向**：只呈现可学的好做法。绝不出现"谁不行 / 谁比你强 / 谁领导力弱"这类比较或负面评价。
- 片段里夹带他人敏感信息（薪酬、隐私、纪律）时，剔除后再呈现。

## 红线（越过就停）

- 不点名、不暗示身份。
- 不给任何人的领导力打分、排名、评级。
- 不生成"某同事的领导力画像/档案"。
- 不推测他人动机、性格、忠诚度、心理状态。
- 用户若把它当"帮我评判某人 / 谁比谁强 / 该跟谁"，明确拒绝，拉回"这类情境你想怎么处理得更好"。
