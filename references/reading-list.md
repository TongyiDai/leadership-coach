# 书单 · 按方向对口推荐

**用法：轻量、克制。** 不掉书袋、不做读书清单轰炸。只在诊断出某方向的问题、给完改进动作后，**顺手推荐一本最对口的书**（一次最多一本），作为想深入的人的下一步。用户没表现出兴趣就不必每条都推。

推荐格式（附在改进动作后一行即可）：

> 📖 想系统深入：《书名》—— 一句话为什么对口。

## 方向 → 一本对口的书

| 诊断方向 | 推荐 | 为什么对口 |
|---|---|---|
| 提问 vs 告知 / 教练式 | 《高绩效教练》John Whitmore | GROW 的原书，讲透"少给答案、多问问题" |
| 反馈与纠偏 | 《Radical Candor 绝对坦率》Kim Scott | 关心+直接两维度，破"滥情/进攻"两个坑 |
| 冲突处理 / 高风险对话 | 《关键对话》Patterson 等 | 高情绪、高分歧、高风险时怎么把话说下去 |
| 向上沟通与影响 / 跨部门推动 | 《影响力》Cialdini | 无正式职权时靠什么让人说"好" |
| 会议表达与说服 | 《金字塔原理》Barbara Minto | 结论先行、结构化表达，会上说到点上 |
| 授权赋能 / 带人 | 《一分钟经理人》Blanchard | 情境领导的通俗入门，按成熟度授权 |
| 目标对齐与决策 | 《OKR 工作法》Doerr《这就是 OKR》 | 目标怎么设、怎么对齐、怎么讲进展 |
| 激励与留人 | 《驱动力》Daniel Pink | 自主/精通/意义——比奖金更持久的动力 |
| 新任管理者转型 | 《成为管理者》Linda Hill / 《领导梯队》Charan | 从"自己做"到"带人做"的换挡之痛 |
| 团队协作氛围（带团队） | 《团队协作的五大障碍》Lencioni | 信任→冲突→承诺→担责→结果的修复顺序 |
| 全局领导风格 | 《什么是领导力》Goleman(HBR 合集) | 六种风格按情境切换，别只会一招 |

## 边界

- 只做**书名 + 作者 + 一句话理由**的归属式推荐，**不放任何书的正文、摘要、章节内容**（版权）。
- 一次诊断里推荐的书**不超过 2 本**，优先只推首要方向那一本。
- 这些是通用经典，不替代 skill 自己的诊断——书是给"想再往深走一步"的人，不是每条建议的标配。
