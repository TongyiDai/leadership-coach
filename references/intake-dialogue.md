# 开场多轮对齐 · 教练契约问诊脚本

有针对性的提升，前提是先知道**练什么**和**从哪起步**。这一步不读飞书，只与用户对话，产出一个明确的"方向 + 阶段 + 场景"三元组，写入私有状态，成为后续诊断和陪练的靶子。

## 为什么要先对齐

领导力是个大筐，而且**不等于有下属**——对个人贡献者，它是无正式职权下的影响力：把事推动成、把人说服动、把话在会上讲清。不对齐就直接读会议记录做诊断，会得到一堆"泛泛正确但没人想改"的建议。先让用户自己说出最想突破的方向和当前所处的位置，诊断才能收敛、改进动作才能落地。这也是标准教练关系里的 **contracting（约定）** 环节。

## 三件必须问清的事

用 AskUserQuestion 分步收敛，不要一次抛一张问卷。

### 问题 1 · 想提升的方向（多选）

最想在哪些领导力维度上变强。给这几个候选（对应后续框架）。**无下属的个人贡献者**重点看前四项：

| 方向 | 一句话 | 适用 | 主挂框架 |
|---|---|---|---|
| 向上沟通与影响 | 向上级/资深方汇报、争取资源没底气 | 所有人 | SCARF / GROW |
| 跨部门推动 | 没有汇报线，推不动横向协作 | 所有人 | SCARF |
| 会议表达与说服 | 会上说不到点、压不住场或被带偏 | 所有人 | GROW / SBI |
| 反馈与纠偏 | 该说的没说清，或说了伤人 | 所有人 | Radical Candor / SBI |
| 冲突处理 | 回避冲突或激化冲突 | 所有人 | SCARF / Radical Candor |
| 目标对齐与决策 | 目标传递失真、决策拖延 | 所有人 | GROW / OKR 对齐 |
| 授权赋能与带人 | 该放手的没放手，事必躬亲 | 有下属 | 情境领导 |
| 激励与留人 | 团队动力不足、核心想走 | 有下属 | SCARF / 情境领导 |

多选可以，但提醒用户**排出首要方向**——诊断会重点打这个。

### 问题 2 · 当前所处阶段（单选）

用简版领导力成熟度量表让用户自评现在的位置。这决定诊断的标尺（对个人贡献者和对战略型领导，同一个行为的评判完全不同）：

| 阶段 | 定义 | 典型课题 |
|---|---|---|
| 个人贡献者 | 无下属，靠专业与影响力做事 | 无职权影响力、向上沟通、跨部门推动、会上说服、带没有汇报关系的人做事 |
| 新任管理者 | 刚从个人贡献者转管理，0–1 年 | 从"自己做"转向"带人做"；放下亲手做的冲动 |
| 一线带人 | 稳定带一个小团队 | 反馈、授权、把事分出去、带出人 |
| 带团队的团队 | 管理管理者（M2+） | 通过他人的团队拿结果；定标准、搭机制、育将 |
| 战略型领导 | 对业务/组织负方向 | 定方向、跨部门影响、组织能力、取舍 |

### 问题 3 · 近期最想解决的一个真实场景（自由描述）

请用户描述一个最近真实卡住的场景（谁、什么事、卡在哪、你怎么处理的、结果）。对个人贡献者，这可能是一次跨部门争取、一次向上汇报、一次会上没说服成的提案。这个场景会：
- 成为阶段 4 陪练的默认剧本；
- 成为阶段 3 诊断时的重点回溯对象（去飞书里找这件事的会议/沟通证据）。

## 落盘

三项收敛后写入私有状态：

```bash
python3 scripts/state.py set-intent \
  --direction "跨部门推动" --direction "会议表达与说服" \
  --stage "个人贡献者" \
  --scene-tag "跨部门争取资源未果"     # 只存脱敏短标签，不存场景原文细节
```

`--scene-tag` 只存一个便于回溯的短标签，场景的敏感细节留在对话里、不落盘。

## 收尾话术

对齐完，用一句话向用户确认教练契约，再进入飞书取证：

> "这次我们主要练**跨部门推动**（你现在在**个人贡献者**阶段），围绕你说的那次争取资源没成的事。接下来我读一下你近 30 天在项目会和关键沟通里的真实发言，照出这个方向上的具体问题，再和你一条条过。可以吗？"
>
> 定期复盘模式（每周一 10:30）则跳过对齐，直接说："上周的领导力复盘来了，我读了你上周的会和关键沟通，聚焦你定的**跨部门推动**方向，重点看上次那件最该改的事有没有改善。"
