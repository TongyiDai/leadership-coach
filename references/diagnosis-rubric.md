# 领导力诊断卡 · 评分口径与证据分级

阶段 3 的诊断输出规范。目标：每条结论都**挂真实飞书证据、挂成熟框架、给可落地动作**，不做空泛点评，不越界到绩效/人格判断。

## 证据分级（每条证据必须标）

借 one-on-one-manager 的分级，防止把推断当事实：

| 级别 | 含义 | 例子 |
|---|---|---|
| **事实** | 逐字记录/文档里可回溯的客观行为 | "周会上你连续说了 6 轮指令，中间没有提问" |
| **本人已表达** | 本人自己写下/说过的判断 | "你在复盘文档里写'我可能管得太细'" |
| **观察** | 从多条证据归纳的模式 | "近 4 场会你都在别人说完前接话" |
| **待验证推断** | 需要本人确认的假设，不作事实 | "这可能让下属不敢提反对意见——需要你确认" |

高置信度结论至少要有两条"事实/本人已表达"级证据支撑；单条证据的结论标为"观察"或"待验证推断"。

## 诊断维度评分卡（1–5，锚定行为）

按用户选定方向，挑相关维度打分。**分数只对本人、只为看趋势，不对标他人、不进任何人事流程。**

| 维度 | 1 分（待发展） | 3 分（可用） | 5 分（示范） | 主挂框架 |
|---|---|---|---|---|
| 提问 vs 告知 | 几乎只下指令 | 指令与提问混合 | 用问题引导对方想通 | GROW |
| 反馈质量 | 回避真问题或只批评 | 会给反馈但不够具体 | 关心+直接+具体(SBI) | Radical Candor/SBI |
| 授权程度 | 事事插手 | 部分放手 | 按成熟度精准授权 | 情境领导 |
| 心理安全 | 常触发地位/公平威胁 | 中性 | 主动营造安全感 | SCARF |
| 目标对齐 | 目标传递失真 | 目标清晰但对齐弱 | 目标+对齐+进展透明 | GROW/OKR |
| 冲突处理 | 回避或激化 | 能压住场面 | 把分歧转成建设性讨论 | SCARF/Radical Candor |

评分附一句锚定证据，别只给数字。

## 每条诊断结论的固定结构

```
【问题】<一句话点出盲点>
【证据】<去标识的本人原话/行为> · 分级：<事实/本人已表达/观察/待验证推断> · 来源：<会议逐字/OKR/文档，日期>
【框架归因】<挂到具体框架的哪一点，说清为什么这是问题>
【改进动作】<下一场会/下一次1:1 能直接用的具体做法：给话术/问句/结构>
```

**示例：**

```
【问题】团队周会上你几乎只在下指令，很少给下属发言和自己想方案的空间。
【证据】最近 3 场周会逐字记录里，你的发言 82% 是陈述式指令，仅 2 处提问；
        多次在下属话说到一半时接过话头。分级：事实 · 来源：周会逐字，08-05/08-12/08-19
【框架归因】GROW 缺 Options/Will——方案全由你给，下属没机会生成自己的选项；
        同时触发 SCARF 的 Status 与 Autonomy 威胁，久了团队会等你拍板、不主动。
【改进动作】下次周会试"先问后说"：每个议题先抛一个开放问题（"你会怎么推进？还有别的路吗？"），
        等对方给出至少一个自己的选项再补充；把"我觉得这样做"换成"你觉得哪条路更稳，为什么"。
```

## 报告组织

1. **教练契约回顾**：一句话重述本次聚焦的方向、阶段、场景（来自阶段 1）。
2. **证据覆盖说明**：哪些资产纳入、时间窗、条数、缺失。
3. **聚焦方向的诊断**：3–5 条，按上面结构，重点打用户选定方向。
4. **附带观察**：其余方向上顺带发现的 1–3 条，简列。
5. **本次最该改的一件事**：从所有结论里挑出 ROI 最高的一个动作，作为下次复盘的锚点。

## 边界（诊断时必须守）

- 不评价下属、不给任何人贴标签、不推测他人动机（只从本人行为找本人的改进点）。
- 不产出绩效结论、晋升建议、离职预测。
- 发现健康/家庭/薪酬/纪律等敏感信息时停止扩展，最小保留。
- 全篇去过程叙述、去口径声明，像一份成品交付。
