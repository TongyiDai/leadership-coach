# 隐私与威胁边界

本 skill 处理管理者本人在会议里的真实发言，是高度敏感的自我数据。隐私模型从严。

## 数据最小化

**长期状态（`state.json`）只允许保存：** 时间、时区、提升方向、当前阶段、脱敏场景标签、上次诊断成功点、去标识指纹。

**以下内容只在当前进程内处理，绝不落长期状态、日志、图片：** 会议逐字记录全文、本人发言原文、他人发言、人员标识、聊天标识、文档 token/正文、会议 ID、OKR 明细、授权链接、device code。

诊断报告成品（`outputs/*.md`）已去标识——他人一律 `[对方]`，本人原话可保留（那是本人自己的话、交给本人自己看）；但不落他人评价、薪酬、等级等第三方敏感信息。

## 他人数据的处理

- 会议里**他人的发言只用于让本人发言有上下文**，进入分析和落盘前必须去标识（`scripts/extract_speaker_turns.py` 已把他人替换为 `[对方]`）。
- 绝不对他人做画像、评分、动机推测。只从本人行为找本人的改进点。

## 读权限的真实含义

- 搜索可见 = 当前用户身份在该查询下可发现对象；搜不到不证明无权限或对象不存在。
- 逐字记录 `forbidden` / `not found` = 证据不可用，不能解释为"没这场会"或"本人没发言"。
- 部分租户因管理员策略、应用权限或授权缺失返回不完整结果，如实标注。

## 安全门槛

- 身份或租户不明时停止。
- 仅本人自读：只处理当前登录用户本人数据，结论只回本人。任何"帮我看看下属/同事的领导力"请求一律拒绝。
- 不写飞书、不发消息、不改纪要、不下载附件。
- 公开日志与错误报告先删业务正文、发言原文、链接参数、人员标识和 token。
- 不把原始数据发给外部服务；模型调用遵循当前 Agent 宿主的数据政策。
- 不在不同租户/profile 间复用状态，建议按租户使用独立状态路径（`LEADERSHIP_COACH_STATE_PATH`）。
- 发现健康、家庭、薪酬、纪律、医疗等敏感信息时停止扩展读取，最小保留。

## 用途红线（不可用于）

员工监控、HR 绩效评估、晋升/调薪/离职决策、招聘、教育测评、对任何第三方的画像。本 skill 只为**管理者本人自愿的自我提升**服务。

## 删除

用户删除私有状态目录即可清空配置与指纹，下次运行回到首次激活流程。
