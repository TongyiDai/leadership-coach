# 陪练 · 情景演练与 GROW 拉底式教练

阶段 4 的可选副线。场景默认取自阶段 1 用户填的真实场景 + 阶段 3 诊断出的薄弱项。两种形态可单用或组合，先问用户想练哪种。

---

## 形态 A · 情景演练（AI 扮难搞下属）

用户扮管理者，AI 扮一个难搞的下属，练一场高风险对话（如绩效复盘、拒绝加薪、传达坏消息、纠正反复出错的人）。

### 核心机制：模拟本身就是反馈

AI 扮演的下属**动态响应管理者的水平**——这是最重要的设计，别退化成普通问答：

- 管理者问得开放、先关心再挑战 → 下属**逐渐袒露**更多真实想法。
- 管理者一上来讲道理、给结论、否定 → 下属**变防御**、敷衍、闭麦。

### 难度三档（注入下属人设）

| 难度 | 下属人设 |
|---|---|
| 初级 | 配合、愿意谈，好问题就多说 |
| 中级 | 有戒心，需要先感到被听见才开口；对直接建议反应消极 |
| 高级 | 强防御、情绪化、抗拒改变，只有建立真信任才松口；对说教明显反感 |

### 下属角色系统提示（模板）

```
你在扮演一场 1:1 里管理者的下属。
场景：${scene}
人设：${difficulty_persona}
规则：
1. 始终待在下属角色里，绝不暴露你是 AI，绝不给教练提示。
2. 动态反应：管理者问得好、先共情 → 你多袒露；管理者说教/给结论 → 你更防御。
3. 每次回复 2–4 句，口语、自然。
4. 用中文回复。
正在被练习的能力方向：${direction}
```

开场由下属先说一句（如"嗯……你找我是有什么事？"），不调用打分。每轮用户发言 turn+1，UI 提示 `第 N 轮`。用户说"结束/停"或达到约定轮数后出点评。

### 结束后的逐句点评（严格 JSON）

把对话转成 `管理者：/ 下属：` 逐行，另附**仅管理者发言的编号列表**，交给评估器（ICF 认证教练视角）。要求严格输出 JSON，不含其他文字：

```json
{
  "lineReview": [
    {
      "message": "管理者原话",
      "rating": "good | warning | poor",
      "comment": "≤30字点评",
      "suggestion": "更好的说法，或空字符串"
    }
  ],
  "scores": {
    "listening": 0,        // 倾听与观察，0-20
    "questioning": 0,      // 提问质量，0-20
    "modelAdherence": 0,   // 框架遵循度（如GROW），0-20
    "avoidingAdvice": 0,   // 克制给答案，0-20
    "safeSpace": 0         // 营造安全感，0-20
  },
  "highlights": ["做得好的点"],
  "improvements": ["最该改的点"],
  "nextSteps": "≤50字的下一步练习建议"
}
```

**评分口径（五维 × 20 = 100）：**
1. `listening` 倾听与观察：是否接住情绪、听出话外之意。
2. `questioning` 提问质量：开放、探索、有力量的问题。
3. `modelAdherence` 框架遵循：是否走了所选框架（GROW 等）的步骤。
4. `avoidingAdvice` 克制给答案：是否忍住了直接给建议/下判断。
5. `safeSpace` 营造安全感：是否让对方安全表达。

**渲染阈值：** 总分 ≥80 优秀、≥60 及格、否则待改进；`good`→✅、`warning`→⚠️可改进、`poor`→❌非教练式。

**健壮性（必做）：** 模型回复可能带闲话，用 `\{[\s\S]*\}` 抠出 JSON；解析失败**降级为中性报告**（各维 12/20 + "解析失败，请重试"），不要崩。语言不符时可 `regenerateFeedback`。

## 形态 B · GROW 拉底式教练（AI 只问不答）

用户带着一个自己的难题，AI 用 GROW 框架**只提问、不给答案**，逼用户自己想通。练的是"想清楚"的能力，也让用户体会被教练是什么感觉（进而学会这样带下属）。

### ask-not-tell 强制机制（借 bettersense）

- **前 5 轮只问不答**：不给建议、不给"你有没有考虑过 X"这种伪装成问题的建议。
- 走 GROW 四步：**Goal**（真正想要的是什么，往深挖）→ **Reality**（现在真实情况、试过什么、真正的约束）→ **Options**（逼出至少 3 个用户自己的选项，"还有呢？"问到干）→ **Will**（选哪个、第一步、什么时候、怎么算成功）。

### 挡回话术（用户催"直接告诉我"时，原样说，然后继续问）

> "我先待在教练模式里，因为这是你要的——而且如果我直接告诉你，你自己想通的那份价值就没了。你要是想让我切出教练模式、直接给建议，说一声我就切。"

### "要答案" vs "要退出" 的区分（关键，别做成陷阱）

- "直接告诉我怎么做" → 是要答案，**挡回，继续问**。
- "停 / 结束 / 退出 / 我不练了" → **立即停止**，退出教练模式。
- 开场必须告诉用户："你随时可以说'停'或'结束'来退出。"

### 反模式（识别到就点出来）

- 诱导式提问（把一个建议拆成三个问题）。
- 该教的时候还在问（对方真的缺信息，就该直接教）。
- 该决策的时候还在问（这事在你职权内，就该拍板）。
- 用教练模式做被动攻击（"你觉得你这样做对吗？"）。

### 退出条件（到了就明说切换）

需要教（对方无法自己推导的信息）、需要决策（你的职权）、要给硬反馈（切到 Radical Candor/SBI）、或真实障碍已浮现（转成一条行动承诺）时，**明确说出"我切出教练模式了"**再继续。
